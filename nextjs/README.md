# Infoplaza Platform — Next.js Example

Example implementation of the [Infoplaza Platform API](https://platform.infoplaza.com/) using [Next.js](https://nextjs.org/).

> 🚧 **In progress** — this is the first implementation in this repository and is currently being built. Check back soon!

## What this example will cover

- Fetching data from the Infoplaza Platform API from Next.js server components and API routes
- Keeping your API key secure using environment variables
- Displaying weather, geo and mobility data in a clean, modern UI

See the [repository README](../README.md) for an overview of all planned implementations.
